# Getting help

`iac-scanner` is a community-maintained open source project. Please use the channel that matches your question:

| You want to…                                                     | Use this channel                                                                          |
|------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| Report a reproducible bug                                        | [Open a bug report](https://github.com/alphacrack/iac-scanner/issues/new?template=bug_report.md) |
| Request a feature or new IaC type                                | [Open a feature request](https://github.com/alphacrack/iac-scanner/issues/new?template=feature_request.md) |
| Ask "how do I…?" / share a use case / discuss design             | [Discussions](https://github.com/alphacrack/iac-scanner/discussions) (if enabled), otherwise an issue with `kind:question` |
| Report a **security vulnerability**                              | See [SECURITY.md](SECURITY.md) — **never** use public issues for this                     |
| Submit a fix or improvement                                      | [CONTRIBUTING.md](CONTRIBUTING.md) (PR targets `development`, signed off)                 |
| Read docs, tutorial, blog                                        | [bishwasjha.github.io/iac-scanner](https://bishwasjha.github.io/iac-scanner/)             |
| Read the changelog                                               | [CHANGELOG.md](CHANGELOG.md)                                                              |

## Supported versions

Only the latest minor release line receives bug and security fixes. See [SECURITY.md](SECURITY.md) for the supported-versions matrix.

## Response expectations

This is a volunteer-run project. We aim for:

- **Security reports:** acknowledgement within 72 hours.
- **Bug reports:** triage within a week.
- **Feature requests / discussions:** best effort; if you need a faster turnaround, pair the request with a PR.

If your question stalls and you think it's been missed, a friendly bump on the issue is fine.

## Commercial support

There is no paid support tier today. If you need one, please open a discussion describing your use case — it helps us understand the demand.
