# Maintainers

This file is the canonical list of people authorized to merge PRs, cut releases, and act on security reports. It is intentionally short — see [GOVERNANCE.md](GOVERNANCE.md) for how this list changes.

CODEOWNERS in [.github/CODEOWNERS](.github/CODEOWNERS) mirrors this list and is what GitHub uses to auto-request reviews.

## Becoming a maintainer

See [GOVERNANCE.md → Roles](GOVERNANCE.md#roles). In short: invitation-only, after a sustained track record of high-quality contributions and reviews. A new maintainer is added by PR to this file + `.github/CODEOWNERS`, with approval from a majority of current maintainers.
